## ✨ Features

- **Cybernetic & Industrial Aesthetic**: Dark mode with cyan/emerald glassmorphism gradients and subtle grid lines.
- **Hero & Profile Avatar**: Highlighting profile photo, title, contact pills, and quick action buttons.
- **Telemetry Dashboard**: Highlighting 4+ projects, 3+ certifications, 7.44 CGPA, and 100% water overflow prevention efficiency.
- **Filterable Technical Arsenal**: Interactive skill categories (Simulation, Programming, Data Analytics, Microcontrollers, Web & AI).
- **Interactive Project Showcase**: Detailed modal popups showcasing hardware specs, sensor logic, and circuit simulation suites.
- **Quantifiable Certifications**: Featuring assessment scores (Excel 92%, MATLAB 100%, Prompt AI 90%) and credential link placeholders.
- **Responsive Navigation**: Upgraded hamburger menu drawer with smooth glassmorphism animations for mobile viewports.

## 🛠️ Local Development & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rohitghadi25122004/PortfolioManjushree.git
   cd PortfolioManjushree
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build production bundle**:
   ```bash
   npm run build
   ```
